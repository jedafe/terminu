# Command Manifest Format

Structured command definitions consumed by Command Intelligence (§04).
Manifests live in `registry/` as YAML; discovery-generated manifests are
normalized to the same schema.

```yaml
id: docker.container.logs           # required, unique, dotted namespaced
application: docker                 # owning CLI
name: View Container Logs           # human label (palette/context UI)
description: Stream logs for a container
parameters:                          # optional
  - name: container
    type: resource                   # resource | string | number | boolean | enum
    resource: docker.container       # resolved via target providers
    required: true
    flag: null                       # positional if null; "--name" if flag
command:
  executable: docker                 # required — never interpolated
  arguments: [logs, "{container.id}"]# template refs to params only
execution:
  risk: controlled                   # informational|controlled|confirmed|restricted
  confirmation: true                 # required when risk ≥ controlled
  timeout_s: 0                       # 0 = none
  working_dir: "{session.cwd}"       # resolution context
context:                             # when this command is relevant
  processes: [docker]                # show when docker detected in session
  files: []                          # show when matching files in cwd
tags: [docker, logs, ops]
source: builtin                      # builtin | discovered | custom
```

## Hard rules

- `executable` + `arguments[]` only — never a shell string; template refs
  bind to declared params, resolved as argv values, never text-substituted
  into a command line.
- `risk` ≥ `controlled` implies the broker confirmation path (ADR-004).
- `type: resource` params resolve through the resource provider — the
  manifest never embeds live values.
- `source: discovered` manifests are generated by auto-discovery
  (`--help`/completion parsing) and marked provisional in the UI.
- New manifest fields must be added to this file first (Rule 11).
