# ideas/

Uncommitted product/feature ideas that don't yet map to a roadmap phase
(Rule 10 gate). Format: `idea-slug.md` with problem, proposed scope, and
why it's not a phase yet. An idea graduates to a phase via an ADR or a
roadmap update — never straight into code.

Seeded candidates (from brief §13 deferred table, if/when demanded):
desktop wrapper, agent daemon, plugin SDK, orgs/OIDC, workflow engine,
WebDAV/SCP providers, multi-node scale.
